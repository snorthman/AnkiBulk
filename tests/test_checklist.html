Actions to perform in Anki with the AnkiBulk addon running

Opening & Setup

Prereq: Have a collection with at least 3-4 cards of the same notetype.
Select 3+ cards in the browser, then open AnkiBulk > Bulk Add.
Dialog opens. Example rows (grey, read-only) appear for each selected note. One blank editable row at the bottom. Notetype chooser is locked. Deck chooser reflects the first card's deck.
Close the dialog. Deselect all cards in the browser, then reopen AnkiBulk.
Dialog opens with no example rows. Notetype chooser is unlocked. One blank editable row.
With the dialog open (no selection), change the notetype via the notetype chooser.
Table columns update to match the new notetype's fields. Sort field column header has "(sort field)" suffix.

Cell Navigation

Double-click a cell to enter edit mode. Type some text. Press Tab.
Commits cell, moves to the next visible column in the same row. At the last column, wraps to the first column of the next row.
In edit mode, press Shift+Tab.
Moves to the previous visible column. At the first column, wraps to the last column of the previous row.
In edit mode, type "hello". Place cursor at the end of the text. Press →.
Commits cell and moves one cell to the right (single step, not double).
In edit mode, place cursor at position 0 (start of text). Press ←.
Commits cell and moves one cell to the left. Does NOT trigger when cursor is at position 1 or later.
In edit mode, press → when cursor is in the middle of the text.
Cursor moves within the text normally. Does not leave the cell.

Row Creation & Deletion

On the last editable row, type text in any cell (not just sort field). Press Enter.
A new blank row is created below. Cursor moves to that row, same column.
On the last editable row, leave all cells empty. Press Enter.
No new row is created. Cursor stays on the current row.
On the last editable row with content in a cell, press ↓.
A new blank row is created. Cursor moves down, same column.
On the last editable row with all cells empty, press ↓.
No new row is created.
Click the Insert Row button when the last row has content.
A new row is inserted below the current row. Current column is maintained.
Click the Insert Row button when the last row is completely empty.
No new row is added. Cursor jumps to the empty last row, same column.
Select a row in the middle. Click the Delete Row button.
Row is removed. Cursor moves to the same position (or last row if at end). Current column is maintained.
Delete all editable rows until only one remains.
The last editable row cannot be deleted. At least one editable row always exists.

Selection & Multi-select

Click a cell, then click-drag across multiple cells.
All cells in the drag range are selected (highlighted).
Click a cell, then Shift+click a distant cell.
Rectangular selection from the anchor cell to the shift-clicked cell.
Click a cell, then Ctrl+click additional individual cells.
Each Ctrl-clicked cell is added to the selection independently.

Backspace & Delete Keys

Select a single cell with text (not in edit mode). Press Backspace.
Cell text is cleared and cell enters edit mode (cursor blinking in the now-empty cell).
Select multiple cells across editable rows. Press Backspace.
Only the anchor cell (the first cell clicked) is cleared and enters edit mode. Other selected cells are untouched.
Select multiple cells with text. Press Delete.
All selected editable cells are cleared. No cell enters edit mode.
Select all cells of a single editable row (which has some text). Press Delete once to clear, then Delete again.
First press clears all cells. Second press deletes the row entirely (since all cells are empty and it's a single-row selection), unless it's the only editable row.
Try pressing Backspace or Delete on a read-only (grey) example row.
Nothing happens. Read-only cells are never modified.

Context Menu (Right-click)

Right-click on an editable cell with content. Choose Copy.
Cell content is placed on the clipboard.
Select a 2×2 block of cells with content. Right-click > Copy. Open a text editor and paste.
Clipboard contains tab-separated values with newlines between rows (e.g. a\tb\nc\td).
Copy a 2×2 block from Excel or a spreadsheet. Select a cell in AnkiBulk. Right-click > Paste.
Content fills cells starting from the selected cell, respecting visible columns. All pasted cells become selected.
Copy 3 rows of data. Paste into a table that only has 1 editable row.
Two additional rows are created to accommodate the pasted data. All pasted cells selected.
Select editable cells with content. Right-click > Clear.
All selected editable cells are emptied.
Right-click on a read-only example row.
Copy is enabled. Paste and Clear are disabled.

Keyboard Shortcuts

Select cells, press Ctrl+C, then select a different cell and press Ctrl+V.
Identical behavior to the context menu Copy/Paste. Pasted cells are auto-selected.
Make some edits to cells. Press Ctrl+Z.
Last change is undone. Undo button in toolbar reflects state.
After undoing, press Ctrl+Y.
Change is redone. Redo button in toolbar reflects state.
While a cell editor is open (in edit mode), press Ctrl+C and Ctrl+V.
Normal text editing copy/paste within the cell. Does NOT trigger the table-level copy/paste.

Undo & Redo

Type text into a cell, press Enter to commit. Click the Undo toolbar button.
Cell reverts to its previous content. Undo button disables when the stack is empty.
Undo an action, then click the Redo toolbar button.
Change is reapplied. After making a new edit, redo stack is cleared.
Delete a row, then undo.
The deleted row reappears with its content intact.

Column Visibility

Right-click on the table header row.
A menu appears with checkboxes for each column. Sort field column checkbox is disabled (cannot be hidden).
Uncheck a column in the header context menu.
Column disappears. Menu stays open. Re-checking brings it back. Preference persists across sessions.
Hide a column, then use Tab to navigate through cells.
Tab skips the hidden column.

Table / Text Toggle

Add some editable rows with data. Click the toggle to switch to Text view.
Text view shows YAML. Upper pane has example notes (read-only), lower pane has your editable notes.
In Text view, edit the YAML (valid changes). Toggle back to Table.
Table reflects the YAML changes. Data round-trips correctly.
In Text view, introduce a YAML syntax error (e.g. unclosed quote). Toggle back to Table.
A warning dialog appears. You can either cancel (stay in Text) or discard (return to Table with original data).
On first-ever launch, observe the yellow hint label. Switch to Text view and back.
Hint disappears permanently after switching to Text view once.

Update from Selection (Ctrl+R)

With the dialog open, change your browser selection to different cards (same notetype). Press Ctrl+R.
Example rows update to reflect the new selection. Your editable rows are preserved.
Select cards of a different notetype. Press Ctrl+R.
A confirmation dialog warns about the notetype change and that editable data will be lost. Cancelling keeps old state.
Deselect all cards in the browser. Press Ctrl+R.
Example rows are removed. Editable rows remain. Notetype chooser becomes unlocked.

Clipboard Toolbar Buttons

Click the Copy Table toolbar button (clipboard icon).
Entire table (header + all rows, visible columns only) is copied as TSV. Tooltip confirms.
Copy a list of words (one per line) to the clipboard. Click the Paste Clipboard toolbar button.
Each line becomes a new row with the text in the sort field column. A tooltip shows how many rows were added.
Clear your clipboard (copy empty text). Check the paste button.
The paste toolbar button is disabled (greyed out).

Bulk Add

Add 2-3 editable rows with content in the sort field and other fields. Click Bulk Add.
Notes are created. Tooltip says "N notes added". Dialog closes. Browser shows the newly added notes.
Add rows where some have content in non-sort fields but the sort field is empty. Click Bulk Add.
A warning dialog appears: "N rows have no content in their sort field and will be discarded. Continue?" Only rows with sort field content are added.
Leave all editable rows empty. Click Bulk Add.
Tooltip says "No new notes to add". Nothing happens.
Fill in Tags column for a row. Click Bulk Add.
The created note has the specified tags when viewed in the browser.

Dialog Lifecycle

Add content to editable rows. Click Cancel or close the window.
A confirmation dialog asks whether to discard unsaved entries. Cancelling keeps the dialog open.
With no editable content, close the dialog.
Dialog closes immediately without confirmation prompt.
Resize the dialog, close it, then reopen.
Dialog reopens at the same size and position.
With the dialog open, interact with the browser (click cards, navigate).
Dialog stays open (non-modal). Browser is fully interactive.
